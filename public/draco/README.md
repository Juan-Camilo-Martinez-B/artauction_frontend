# Decodificador Draco

Copia de `three/examples/jsm/libs/draco/gltf/` (three.js, MIT; Draco de Google, Apache 2.0). La sala 3D y el visor de la ficha lo usan para abrir modelos GLB con geometría comprimida con Draco, sin pedir nada a un CDN externo.

Al actualizar `three`, vuelve a copiar los tres archivos desde esa carpeta.
