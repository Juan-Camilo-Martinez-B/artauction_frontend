# Texturas de la sala 3D

Texturas PBR de [Poly Haven](https://polyhaven.com), publicadas bajo [CC0](https://polyhaven.com/license): dominio público, sin obligación de atribución. Igual dejamos el crédito.

Cada carpeta trae la versión 1K en JPG: `diff.jpg` (color), `nor.jpg` (normal en convención OpenGL) y `rough.jpg` (rugosidad). El tamaño real sirve para repetir la textura a escala en `src/lib/gallery/materials.ts`.
